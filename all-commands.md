🚀 ASSTRA Developer Cheat Sheet

🖥️ Backend (FastAPI)
| Task                         | Command                     |
| ---------------------------- | --------------------------- |
| Go to Backend                | `cd backend`                |
| Activate Virtual Environment | `venv\Scripts\activate`     |
| Run Backend                  | `uvicorn main:app --reload` |
| Stop Backend                 | `Ctrl + C`                  |
| Backend URL                  | `http://127.0.0.1:8000`     |


🌐 Frontend (React)
| Task                 | Command                 |
| -------------------- | ----------------------- |
| Go to Frontend       | `cd frontend`           |
| Install Dependencies | `npm install`           |
| Run Frontend         | `npm run dev`           |
| Stop Frontend        | `Ctrl + C`              |
| Frontend URL         | `http://localhost:5173` |


💻 Electron
| Task                 | Command       |
| -------------------- | ------------- |
| Go to Electron       | `cd electron` |
| Install Dependencies | `npm install` |
| Run Electron         | `npm start`   |
| Stop Electron        | `Ctrl + C`    |


📂 Git Commands
Check Status	git status
Stage All Files	git add .
Stage Single File	git add filename
Commit Changes	git commit -m "Your Commit Message"
View Commit History	git log --oneline
View Branches	git branch
Create New Branch	git checkout -b branch-name
Switch Branch	git checkout branch-name
Pull Latest Changes	git pull
Push Changes	git push

| Task                                      | Command                                  |
|-----------------------------------------  | ---------------------------------------  |
| 📦 Install a package                      | `pip install package_name`               |

| 📦 Install specific version               | `pip install package_name==1.0.0`        |

| 📋 List all installed packages            | `pip list`                               |

| 📋 List packages with versions            | `pip freeze`                             |

| 🔍 Check if a package is installed        | `pip show package_name`                  |

| 🔎 Search installed package (Windows CMD) | `pip list \| findstr package_name`       |

| 🔎 Search installed package (PowerShell)  | `pip list \| Select-String package_name` |

| ⬆️ Upgrade a package                      | `pip install --upgrade package_name`     |

| 🗑️ Uninstall a package                    | `pip uninstall package_name`             |

| 📄 Show package details                   | `pip show package_name`                  |

| 📍 Show package installation path         | `pip show package_name`                  |

| 🐍 Show Python version                    | `python --version`                       |

| 📦 Check pip version                      | `pip --version`                          |

| ✅ Use pip with current Python            | `python -m pip install package_name`     |

| ✅ Check package in current Python        | `python -m pip show package_name`        |

| 📄 Save installed packages                | `pip freeze > requirements.txt`          |

| 📥 Install from requirements file         | `pip install -r requirements.txt`        |

| 🩺 Check for broken dependencies          | `pip check`                              |

| ℹ️ Get pip help                           | `pip help`                               |
